🧠 COVID-19 Data Analysis & Dashboard Project (SQL + Tableau):
This project demonstrates end-to-end data analysis using SQL Server for data exploration and Tableau for visualization.
It showcases analytical thinking, data cleaning, transformation, and storytelling through dashboards.

📄 Project Overview:
The COVID-19 Portfolio Project aims to explore and visualize global COVID-19 trends using real-world data.
It combines SQL-based analysis and interactive Tableau dashboards to highlight key insights such as:
Global infection and death rates
Vaccination progress by country and continent
Population impact and recovery trends

🧰 Tools & Technologies:

SQL Server (T-SQL) — for data cleaning and exploration
Tableau Public — for data visualization and storytelling
Microsoft Excel / CSV files — as data sources
COVID-19 Dataset from Our World in Data

📊 SQL Analysis Highlights:

Data cleaning and preprocessing
Joins and subqueries for advanced analysis
Calculating rolling averages, death percentages, and vaccination ratios
Identifying trends in infection and mortality rates
Creating analytical datasets exported for Tableau visualization

📈 Tableau Dashboard Highlights:

Dashboard File: COVID19 DASHBOARD.twb
Key Visuals:
Global overview of total cases, deaths, and vaccinations
Interactive filters by country and continent
Time-series trends of new cases and vaccination progress
Percentage of population infected and vaccinated
Top countries by infection and death rate
