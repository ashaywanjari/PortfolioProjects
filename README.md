🧠 COVID-19 Portfolio Project (SQL Server)

This project demonstrates SQL data exploration and analysis using COVID-19 data. 
It’s designed to showcase SQL Server skills in querying, cleaning, transforming, and analyzing real-world datasets.

📄 Project Overview

The COVID Portfolio Project focuses on analyzing global COVID-19 trends using raw datasets containing cases, deaths, and vaccinations.
Through this project, you’ll explore insights such as:
Infection and death rates by country and continent
Percentage of population infected over time
Vaccination progress across regions
Rolling averages and cumulative statistics

🛠️ Tools & Technologies
SQL Server (T-SQL)
Microsoft SQL Server Management Studio (SSMS)
COVID-19 Data (Our World in Data)

📊 Key SQL Concepts Used

Joins and Subqueries
Temporary Tables
Aggregate Functions (SUM, AVG, MAX, etc.)
Window Functions (e.g., OVER(PARTITION BY...))
Data Cleaning & Transformation
Calculating Rolling Totals and Percentages
